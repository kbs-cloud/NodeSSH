# Changelog - v1.3.1

## Changes & Improvements
- **Manual Session Selection**: File Manager panes will no longer automatically initiate connections on startup or when adding new split panes.
- **Session Chooser Hub**: Unassigned panes now present an interactive session picker allowing you to quickly choose between Local Filesystem, active SSH Terminal tabs, saved SFTP profiles, or connecting to an ad-hoc standalone SFTP host.
