# Changelog

## New Features
- **Resizable Dock Panels**: You can now click and drag the divider bar on docked SFTP file explorer panels and split terminal panes to freely customize their size. Double-clicking any resize divider resets it back to default.
- **Left-Aligned File Actions**: File and folder action buttons (More Options, Download, Edit) are now on the left side of the explorer, making them immediately accessible even with long file names.
- **Per-Tab SFTP Navigation**: Switching between active terminal tabs now seamlessly restores each tab's individual SFTP directory and sync state.

## Changes & Improvements
- Dock panel width preferences are automatically remembered between app restarts.
- Remote folder creation and directory auto-synchronization reliability improved.
